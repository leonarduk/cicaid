Implement Numeric Shortcuts for CACID Actions Based on Logical CICD Sequence

## What

Implement numeric shortcuts for each CACID action, ordered by their logical CICD sequence.

## Why

To simplify the usage of CACID actions and enhance user experience.

## How

Develop a system where each CACID action is assigned a unique numeric shortcut that corresponds to its position in the logical CICD sequence. For example, "CACID 1" would represent the first action in the sequence, "CACID 2" the second, and so on.

## Success looks like

- [ ] Numeric shortcuts are implemented and correctly ordered according to the CICD sequence.
- [ ] The system allows for easy identification and execution of CACID actions using numeric shortcuts.

## Failure looks like

- [ ] Numeric shortcuts are not correctly assigned or do not reflect the logical CICD sequence.
