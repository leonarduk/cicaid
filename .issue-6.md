Simplify Script Naming by Removing Initial Letter Prefixes

## What

Remove the initial letter prefix from script names, for example, changing `o_review_issue.py` to `review_issue.py`.

## Why

It improves the consistency and readability of the script names.

## How

Rename each script file and update any references in other files accordingly.

## Files Affected

src/cicaid_devtools/*

## Constraints

Ensure that all scripts continue to function correctly after renaming.

## LLM tier

sonnet

## Value

Medium Value

## Success looks like

- All scripts are renamed without initial letter prefixes.
- No functional changes are introduced in the codebase.

## Failure looks like

- Errors during script execution due to outdated references.
- Code that no longer compiles or functions as expected.
